# 2026-09-18

## 个人基金收益监控 H5（从零搭建，已完成）

- 技术选型：Vue3 全局构建 + Dexie4 + ECharts5，全部本地化到 `vendor/`，**无 npm、无打包**，
  纯静态可直接推 GitHub Pages（已内置 `.github/workflows/pages.yml` + `.nojekyll`）。
- 存储：`FundMonitorDB` / `funds`(主键 fund_code) + `history_cache`(主键 fund_code)；
  IndexedDB 不可用时自动降级 localStorage → 内存（`assets/js/db.js`）。
- 页面：首页看板（总收益/持仓市值/基金卡片）、添加编辑弹窗、详情页 hash 路由 `#/fund/000001`
  （ECharts 净值走势 + 历史列表）、设置弹窗（导出/导入/清空 JSON 备份）。

### 数据源踩坑（重要）

- `fundgz.1234567.com.cn/js/{code}.js`（老估值接口）**已失效**，全部 404。
- 新浪 `hq.sinajs.cn` 校验 Referer，非新浪来源 403，不可用。
- **主数据源**：`fundmobapi.eastmoney.com/FundMNewApi/{FundMNBasicInformation, FundMNHisNetList}`，
  响应带 `ACAO: *`，浏览器可直连免代理。但**桌面浏览器 UA 会被拒**（返回 ErrCode 61136403「网络繁忙」），
  移动端 UA / 微信内置浏览器正常。
- **兜底数据源**：`fund.eastmoney.com/pingzhongdata/{code}.js`，以 `<script>` 标签加载不受 CORS 限制，
  桌面/移动都可用；含 `fS_name` / `fS_code` / `Data_netWorthTrend`（x=ms 时间戳, y=净值, equityReturn=日涨跌%）。
  体积数百 KB，故内存缓存 10 分钟 + 写入 IndexedDB 缓存 6 小时。
- 名称搜索：`fundsuggest.eastmoney.com/FundSearch/api/FundSearchAPI.ashx?callback=&m=1&key=code`（JSONP，全 UA 可用）。
- 无效代码时 pingzhongdata 返回 404 HTML → 当作脚本解析失败触发 onerror，
  所以 `loadScript` 加了 `failMsg` 参数把这种错误改写成「未查询到该基金」。

### 本机验证手法（可复用）

- Bash 的 Git Bash **缺 coreutils**（mkdir/ls/rm/dirname 都找不到，PATH 里只有 `Git/cmd`）。
  文件与目录操作一律用 node 脚本（fs）或专用工具。
- 无头冒烟：`C:/Program Files (x86)/Google/Chrome/Application/chrome.exe --headless=new --dump-dom
  --virtual-time-budget=40000 --user-data-dir=<profile>`，把 stdout/stderr 用 fs.openSync 的 fd 传给
  execFileSync 的 stdio（cmd.exe 重定向会因引号炸掉）。同一个 profile 可让 IndexedDB 数据跨次运行保留，
  用来预置持仓后测首页/详情页。加 `--user-agent=` 可模拟移动端验证主数据源分支。

## 基金监控 H5：净值走势补充「当天单位净值 + 日涨幅」

用户反馈「净值走势里没有当天的单位净值和日涨幅」，改动集中在 `assets/js/app.js` 的 `FundDetail`：

- 新增 `latest` 计算属性：优先取实时行情 `quote`（nav / rate / navDate），历史数据末点兜底。
- 新增 `chartPoints`：`series`（区间历史）+ 若历史末点日期 ≠ 最新净值日期，则把最新点追加到末尾，
  保证曲线末端就是当天/最新交易日的数据。图表、区间涨跌、明细列表统一改用 `chartPoints`。
- 详情页 `.d-stat` 改为 4 格：单位净值（下方显示净值日期）/ 日涨幅（下方显示「已公布」或「未更新」）
  / 当日收益（下方显示份额）/ 区间涨跌（下方显示区间名）。
- ECharts 改双轴：左轴 单位净值折线（面积渐变）+ 右轴 日涨幅柱状（按正负红绿着色，barMaxWidth 6），
  加 legend；tooltip 同屏显示单位净值与日涨幅。
- 明细列表首行加「最新」标签；列表标题改为「净值明细（单位净值 / 日涨幅，近 N 个交易日）」。

验证（无头 Chrome + 移动端 UA，控制台干净）：
000001 → 单位净值 1.3330(2026-09-18)、日涨幅 +2.70%(未更新)、当日收益 +35.04、区间 -0.45%(近1月)，
canvas 渲染、30 行明细、首行带「最新」标签。

补充说明：09-19 是周六，当日无净值，`settled=false` 所以显示「未更新」——这是有意保留的诚实标注，
盘中/非交易日不会伪装成实时数据。

## 追加：当日净值曲线（分时估值）

关键发现：**官方分时估值接口已下线**。`fundgz.1234567.com.cn/js/{code}.js` 全部 404；
`fund.eastmoney.com/000001.html` 里「净值估算」整段被 `<!-- -->` 注释掉；
`FundMApi/FundVarietieValuationDetail.ashx` 恒返回 Datas null（无论 WAP 还是 Android 参数）。
→ 免费的分时估值序列接口不存在，只能自建采样。

可用的盘中估值字段：`FundMNewApi/FundMNFInfo?...&Fcodes=000001,161725`（批量，ACAO:*，需移动 UA）
返回 `NAV/NAVCHGRT/PDATE`（最新已公布净值）+ `GSZ/GSZZL/GZTIME`（盘中估算，非交易日为 null）。
另：`FundMNBasicInformation` 无 GSZ；`FundMNFInfo` 无 FTYPE/JJGS，所以估值用批量接口、
类型/公司仍走单只接口，两者合并（fetchQuotes）。

实现：
- db.js 升到 version(2)，新增 `intraday` 仓库（主键 fund_code），存
  `{fund_code, date, base(昨收), points:[{t:'HH:mm', v, r}], last_update}`；导出/导入一并带上。
- api.js：`parseBatchItem`/`fetchBatch`/`fetchQuotes`/`recordIntraday`/`getIntraday`；
  同分钟去重、上限 300 点、换日自动重置；仅 `isEstimate` 为真才采样。
- app.js：RANGES 加 `{key:'today'}`；FundDetail 当日档位画估算净值折线（带昨收 markLine 虚线）
  + 日涨幅柱状；有采样点时自动默认切到「当日」；App 每 5 分钟自动刷新采样 + visibilitychange 立即刷新；
  卡片标签改为「盘中估算 / 待更新」。

验证（移动端 UA，控制台干净）：24 点当日曲线渲染正常，最新行 14:45 / 1.2881 / -0.76%，
区间涨跌 -0.76%(当日)，无采样点的基金正常回落到「近1月」。

## 追加：修复图表 hover 无数值显示

用户反馈「鼠标放上去没有具体数值显示」。

排查用 headless Chrome + CDP 做对照实验：纯静态探针页（同 vendor 文件、同配置、
`setOption(opt,true)` 连调 4 次）**内置 tooltip 正常**；真实 `index.html` 完全不显示。
→ 排除配置、多次 setOption、vendor，锁定 Vue 容器环境问题。

决定性探针输出：

```
tooltipViews=1  models=0        ← _componentsModels 里没有 tooltip model
manuallyShowTip 调用次数: 0
_tryShow 调用次数: 1            ← 被调用但
lastX: null, lastY: null        ←  没拿到 dataByCoordSys / target
tooltip DOM: NO_TOOLTIP
```

而**同页面 `updateAxisPointer` 事件完全正常**，payload 含完整 `axesInfo`
（x 轴值 + 两条 y 轴值）。

方案：内置 tooltip 只用来驱动十字准星（`extraCssText:'display:none !important;'` 隐藏弹层，
`show:true` 必须保留 —— 否则 axisPointerModel 不创建、`axesInfo` 恒空），
数值弹层改为监听 `chart.on('updateAxisPointer')` 自建 DOM，定位用响应式 `tipLeft`
+ 固定 `width:168px` 做边界收敛。

踩坑：
1. Vue3 生产构建 `el.__vueParentComponent` 不存在（Vue2 才有），不能从 DOM 反查组件实例。
2. headless Chrome 复用旧 `--user-data-dir` 会 exit=21 静默失败 → 每次换新 profile 目录。
3. `Page.addScriptToEvaluateOnNewDocument` 必须在导航前注入，先建 tab 再注入会抓不到报错（假阴性）。
4. `v-show` 隐藏时 `offsetWidth===0`，用它定位会退化 → 实测 `tip.style.left` 恒为空，
   `$nextTick` 回调路径不可靠，改响应式定位后彻底解决。
5. category 轴 axisPointer 的 x value 是连续值（15.363），需 `Math.round` 才能当 dataIndex。

验证（真实 `Input.dispatchMouseEvent`）：
```

hover(50%) left:241px 2026-08-31 1.3310 +0.99%
hover(75%) left:271px 2026-09-11 1.2540 -0.63%   ← 边界收敛生效
移出图表 hidden:true
切档后   left:181px 2026-08-25 1.2870 -0.77%
JS 错误数 0
```
截图确认弹层位于图例下方、对准 08-31 十字准星，+0.99% 红色（红涨绿跌）。
